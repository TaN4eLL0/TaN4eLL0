## About me

- Mobile developer: I build Android and iOS apps from a single codebase with **Kotlin Multiplatform**, and also with **Flutter**.
- I work on fintech apps: onboarding, registration and payments, the screens where the cost of a mistake is high.
- UI in **Jetpack Compose** on Android and **SwiftUI** on iOS on top of shared Kotlin business logic.
- Navigation and state with **Decompose**, DI with **Koin**, and I have evaluated **Metro** as an alternative.
- I automate routine work: CI on Jenkins, UI tests with Maestro, AI agents for code review built on Claude Code.
- Open to offers and looking for a team with a strong engineering culture.
