## Обо мне

- Мобильный разработчик: пишу под Android и iOS из одной кодовой базы на **Kotlin Multiplatform**, а также на **Flutter**.
- Работаю над финтех-приложениями: онбординг, регистрация, платежи, то есть экраны, где цена ошибки высока.
- UI на **Jetpack Compose** для Android и **SwiftUI** для iOS поверх общей бизнес-логики на Kotlin.
- Навигация и состояние на **Decompose**, DI на **Koin**, пробовал **Metro** в качестве альтернативы.
- Автоматизирую рутину: CI на Jenkins, UI-тесты на Maestro, AI-агенты для code review на базе Claude Code.
- Открыт к предложениям и ищу команду с сильной инженерной культурой.
